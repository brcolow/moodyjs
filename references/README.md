## ASME Case B89-002

*Issues Regarding Granite Surface Plates*, concerning ASME B89.3.7-2013.
Originally approved March 12, 2015; the included version was approved
February 13, 2020.

* [Local PDF](./ASME-B89-002.pdf#page=1), unchanged from the existing local copy.
* [Original ASME source](https://cstools.asme.org/csconnect/FileUpload.cfm?View=yes&ID=61358#page=1).

The README cites page 1, Inquiry 3 and Response 3, which explain that Table 1
tolerances take precedence over calculated values. Section 4.3.4 applies when
the table does not provide a value.

## ISO 8512-2

ISO 8512-2:1990, *Surface plates - Part 2: Granite*. International Organization
for Standardization, first edition, December 1990.

* [Official ISO catalog entry](https://www.iso.org/standard/15737.html).
* [iTeh preview PDF](https://cdn.standards.iteh.ai/samples/15737/840ff16f2c6e45bbac0a9baed880362c/ISO-8512-2-1990.pdf#page=7).

The preview's copyright notice requires written permission for reproduction
(printed page ii, PDF page 2). Only citation details and paraphrased notes are
stored here for this standard.

### Table 1 rounding

Table 1, note 2, on printed page 3 (PDF page 7 of the preview), expresses overall
flatness tolerances to the following precision:

* Grade 0: nearest **0.5 µm**.
* Grades 1, 2, and 3: nearest **1 µm**.

Clause 9.2 refers to Table 1 for preferred plate sizes and Annex D for other
sizes. The nine-page preview contains Table 1 but does not include Annex D.
